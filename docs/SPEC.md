# SPEC — Scientific Guitar Trainer

See `INDEPENDENT_REVIEW.md` for the full rationale. This file is the product spec for the app.

## Problem
Learners get stuck in tab/shape memorization with weak transfer, poor ear, and no raga/blues depth. We want first-principles understanding + measurable skill.

## Users
- Primary: single serious learner (raga + blues focus).
- Secondary: reusable by many (PWA, offline, no accounts).

## Core capabilities
1. Adaptive 15-min sessions from weakest items (SRS).
2. Fretboard drills with mastery tracking.
3. Drone + metronome + mic pitch feedback + recording.
4. Ear training (intervals, chords, degrees, phrases).
5. Raga module (Sa → pakad → ornaments → apply).
6. Blues module (12-bar → chord tones → licks → solo).
7. Curriculum gating + spaced review.
8. Song Lab (key/progression/interval analysis).
9. Fully offline.

## Non-goals
DAW, tuner, tanpura, raga classifier, monolithic AI teacher, tab parroting.
