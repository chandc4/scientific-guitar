# GLOSSARY

- Sa/Re/Ga/Ma/Pa/Dha/Ni: Sargam syllables = scale degrees 1-7.
- Pakad: characteristic phrase defining a raga.
- Aroha/Avaroha: ascending/descending scale of a raga.
- Vadi/Samvadi: most/second-most important notes of a raga.
- Gamaka/Meend/Kan/Andolan/Murki: raga ornaments.
- Thaat/Melakarta: parent scale systems (Hindustani/Carnatic).
- Vector: semitone offset array from root, e.g. [0,4,7].
- Leitner: spaced repetition boxes (1/3/7/14/30 days).
- Gate 1-7: Hear, Explain, Locate, Play, Transpose, Apply, Verify.
- Drone: sustained tonic (tanpura) reference.
